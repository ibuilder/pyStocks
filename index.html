What it does

Seven tabs, one continuously-updating picture of the market.

📅

Multi-horizon estimates

Separate models for next week (short-term reversal + low-vol), month (momentum + quality), and year (12-1 momentum + value), each ranked with a volatility-scaled range and confidence.

⚡

Live intraday technicals

VWAP, opening-range, relative volume, RSI, ATR and the EMA stack computed every minute per symbol off a Redis stream.

📰

News + sentiment

Per-ticker headlines scored with a transparent finance lexicon; sentiment merged into the snapshot so it’s both visible and alertable. Pluggable for FinBERT/LLM.

🔍

Market-wide scanners

Ten built-in scans (gainers, unusual volume, ORB breakouts, oversold/overbought, news movers) plus your own — filtered & ranked live.

🔔

Alert engine

Edge-triggered rules with cooldowns over every indicator (incl. crosses_above), delivered to a desktop toast. Build rules & scans from the UI — no code.

🧪

Validated, not assumed

A point-in-time backtester gates what counts as “actionable”. Walk-forward, realistic costs, and the Information Coefficient — with honest caveats.

Architecture

A hybrid the way the research demands it: a streaming bus for the firehose, Celery for everything scheduled, guaranteed, and retryable.

PROVIDERS (REST / WebSocket: prices · news · fundamentals) │ │ real-time scheduled / on-demand ▼ ▼ INGESTOR (asyncio) CELERY BEAT (scheduler) feed → indicators pre-market screen · intraday (1m) │ XADD news (10m) · alerts · weekly backtest ▼ │ enqueue ┌─────────────── REDIS ───────────────┐ ▼ │ Streams · pub/sub · cache · state │ CELERY WORKERS └──────────────┬───────────────────────┘ indicators · sentiment · alerts · scans ▼ DESKTOP WINDOW (Tkinter, 7 tabs) + toast notifications │ SQLite / Postgres-ready (signals · alerts · backtests · custom scans)

Honest backtest findings

10 years, point-in-time, net of costs. The metric that matters for a ranking model is the Information Coefficient (IC); an IC t-stat above ~2 is the bar for “real”.

HorizonExcess vs benchmarkIC (t-stat)Verdict
Week−2.5%−0.00 (−0.2)No edge
Month+10.1%+0.03 (1.3)Most promising
Year+5.7%+0.04 (0.4)Too few samples

Why this matters

The backtest tells us which signals deserve to be productionised. The weekly reversal signal doesn’t survive costs here; the month horizon is the one worth streaming. Caveats are shown in every tearsheet: fundamentals excluded (no point-in-time data → would leak the future), survivorship bias (current constituents), thin year-horizon samples.

Evaluated & rejected: Kronos

We vetted the Kronos candlestick foundation model as a forecasting upgrade. Three independent backtests, zero-shot. The backtest gate said no — before we added 2 GB of dependencies for it.

TestKronos ICDir-hitBaseline IC
Daily, recent−0.2837.5%+0.36
Daily, 7-yr−0.0545.4%+0.12
Intraday 5m (native)−0.1448.8%+0.06

Discipline over hype

Even on its native intraday domain, zero-shot Kronos showed no usable edge and lost to both the factor model and a one-line momentum rule. Kept the reusable evaluation harness; dropped the weights. Full write-up in KRONOS_EVAL.md.

Run it

Zero-setup desktop app; add Redis to run the background pipeline.

# desktop app (yfinance prototype data)
pip install -r requirements.txt
python app.py

# or build a standalone Windows .exe — no Python needed
pyinstaller stockpredict.spec        # -> dist\stockpredict.exe

# background pipeline
docker compose up -d redis
celery -A stockpredict.celery_app worker --loglevel=info --pool=solo
celery -A stockpredict.celery_app beat   --loglevel=info

# validate the model -> HTML tearsheet
python -m backtest.run --walk-forward --open

# tests
pytest -q
